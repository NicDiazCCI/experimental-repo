# rule-repo

A TypeScript project with Jest testing framework.

## Installation

```bash
npm install
```

## Scripts

- `npm test` - Run tests
- `npm run test:watch` - Run tests in watch mode
- `npm run build` - Build TypeScript files
- `npm run clean` - Remove dist directory

## Development

This project uses:
- TypeScript
- Jest for testing
- CircleCI for continuous integration
