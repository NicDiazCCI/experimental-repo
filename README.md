# rule-repo

**Experimental Repository**

This is an experimental repository for testing and development purposes.

## Setup

```bash
npm install
```

## Scripts

- `npm test` - Run tests
- `npm run test:watch` - Run tests in watch mode
- `npm run build` - Build TypeScript files
- `npm run clean` - Remove build artifacts

## Tech Stack

- TypeScript
- Jest for testing
- CircleCI for CI/CD
